# 勇者アバンド

放置育成 × 協力型オンラインRPG。ドット絵の冒険者を育て、50職の転職、装備の厳選、アクセサリー合成、仲間との自動戦闘を楽しむゲームです。

## 開発状態

設計ベースライン v0.1。ゲーム本体は実装前です。数値は初期調整値であり、プレイテストで検証します。

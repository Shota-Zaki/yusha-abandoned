# スキル・魔法カタログ

## 1. 固定スキルと進化

各職は能動4系統・受動2系統の計6系統を持つ。職業固有特性は別枠で常時有効。能動4系統は全て行動候補にでき、手動で発動せず優先条件を設定する。

各系統Rank0〜20、1点=1Rank。Rank0は未習得。進化閾値はRank1/5/10/20。能動特技は習得済みの下位段階も使えるため、強化により低MP運用が失われない。段階間のRankはその段階の威力・回復・盾量を1Rankごとに2%増加する。強化・弱体の割合にはこの中間Rank増加を使わず、持続だけ1Rankにつき100ms増加する。

物理と魔法の能動特技は全てMPを使用する。基本消費は物理6/10/16/24、魔法12/20/32/48。物理扱いの治療・歌・舞・物資支援も同じ物理MP表。通常攻撃と受動効果は能動特技ではないためMP0。最終消費は50%軽減を下限とし切上げ、能動特技でMP0にしない。

通常の進化名は「技名 → 技名・改 → 技名・真 → 技名・極」。下表の8属性魔法だけは固有の4名称。受動系統も同じ閾値でアイコン枠が進化し、効果量はRankに比例する。

## 6. バフ・デバフの共通契約

同じ効果グループは最も強い値1つを採用。弱い再付与で強い効果を消さない。同じ強さなら終了時刻の遅いものを採用。異なる名前でも同じグループなら重複倍率を増やさない。

通常の能力変化は合算±40%、行動速度変化は±30%、被ダメージ軽減は合算75%まで。能力値からの素の速度は別計算し、最短行動間隔800msを守る。会心率は最大50%、回避率は最大35%。

同種DoT/HoTは1対象あたり最も強い1系統。更新時にtick時刻を早めず、効果元・威力・終了時刻だけ規則どおり更新する。別種のDoTは最大3種。DoTは会心せず、装備の攻撃時追加発動を起こさない。

毒・出血・火傷の割合は敵最大HPではなく攻撃者の攻撃値を参照し、レイドボスのHPを割合で削る抜け道を作らない。

ボスの耐性は敵データに定義し、プレイヤーへ事前表示。効かない妨害をAIが無限に連打しない。シールドの重複は最大HP30%まで、既存分への単純加算ではなく同一グループは強いものを採用する。

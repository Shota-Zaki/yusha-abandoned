# 要件定義

Version: 0.2 / 2026-09-13

`U`はユーザー指定、`A`は確認回答で承認された仕様、`P`は不足を補う仮決定。U/A行にある計算係数などの実装初期値まで永久に固定する意味ではない。確認回答の正本はOPEN_DECISIONS。

## 2. ゲーム上の対象外（v1）

通常フィールドでの無差別PvP、プレイヤーによる強奪、現金賭博、Steamコミュニティ市場への装備出品、無制限の放置蓄積、クライアントだけで確定する交換可能報酬、シームレスな全世界同一マップ、ユーザー運営サーバーの未検証報酬と公式経済の接続はv1の対象外。

定期PvP大会は対象内。Version0.1の「対人PvPは対象外」という包括的な記述は撤回する。

## 4. データ・外部サービス

SteamIDはJSONでは文字列。認証後のSteamIDだけをアカウントキーとして採用する。公式セーブ・キャラクター・所持品・取引の正本は信頼済み保存基盤に置く現行案を維持。Steam CloudやP2P同期だけで報酬の正しさを証明したとは扱わない。

Steam AppID、配布資格、運営基盤の採否/契約、価格登録は外部条件。600円買い切りという販売方式自体は決定済み。未確定の外部条件があっても純粋な戦闘ロジック、カタログ、UI、DB契約の設計・実装は進める。

## 5. 決定・未確定事項の正本

OPEN_DECISIONSに回答済み事項と残るD01/D09を集約する。ONLINE_LIGHTWEIGHTとPVP_TOURNAMENTを基本/詳細設計の追加正本として参照。旧補足ZIPのv0.1.1には今回の価格と大会追加がないため、今回のv0.2を優先する。

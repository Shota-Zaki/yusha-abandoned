# コンテンツ補足 — v0.2への接続と初期案

YA-D03 / 2026-10-02。旧HTML section-5をRepository内の参照可能な詳細設計へ統合する。以下の支給数量/クエスト/消耗品CD/敵係数/ボス周期/共同目標/実績/配分例は**旧補足由来のP（調整可能な設計初期案）**であり、ユーザーが個別に指定・承認した数値、新しいv1必須機能、実装済み内容ではない。既存初期案を見失わないため保持し、採否は対応Taskの設計で判断する。

優先する現行契約: [JOBS](JOBS.md)の職とポイント、[SKILLS](SKILLS.md)の技/MP、[WORLD_MMO](WORLD_MMO.md)の編成と地域、[ITEMS_ECONOMY](ITEMS_ECONOMY.md)の所有権、[COMBAT_CORE_V1](COMBAT_CORE_V1.md)の実装範囲。v1コアは通常攻撃のみで、以下の消耗品/技能/ボスはYA-03/10等の将来範囲。定期大会は[PVP_TOURNAMENT](PVP_TOURNAMENT.md)で別管理する。

支給品を市場へ流さない条件、報酬の一回性、予告攻撃へオート設定で対応する条件、ビルドの同予算比較は現行契約に整合する。無料支給の100Gをキャラ作り直しで反復取得できるか、退会後の一意キー保存、ボス予告と実行タイミング、解除/沈黙の詳細、試験fixtureは実装設計時に検証する。旧記述を競合・バランス・初回体験の受入済み証拠にしない。

以下はv1の仮決定。Repositoryの職業・スキル・ダンジョン定義を置き換えるものではなく、未定義だった開始条件と消耗品・敵行動を補う。

## 1. 初回体験

キャラ作成は1アカウントにつき1活動キャラ。名称は2〜12文字、表示用文字列と検索用正規化を分離する。作成時に初級20職から選び、おすすめは戦士・白魔法使い・黒魔法使い・僧侶の4職。

支給品は選択職に対応した練習武器と防具4点、包帯5個、小マナ薬5個、100G。支給品は本人専用、売価0、分解不可。無料支給品をドロップ品とは区別する。初期職を変えたときは未支給の武器種に限り練習武器を一度だけ支給する。これにより武器制限で初回転職が詰まらない。

チュートリアルは表示・ポイント下書き・NPC編成・1周出撃・受取・装備比較・合成・転職図鑑の順。合成の練習用アクセサリーと霊粉は専用品を使い、試したくないプレイヤーには後回しを許可する。

|クエスト|完了条件|一度だけの報酬|
|---|---|---|
|Q01 冒険者登録|キャラクター作成|上記支給品と100G|
|Q02 作戦の準備|ポイントを保存し、AIルールを確認|包帯3個（本人専用）|
|Q03 街道の踏破|DNG01 NORMALを1回クリア|200G、練習用合成装備1個、アクセサリー1個、合成分の専用霊粉|
|Q04 工房の使い方|任意の練習用合成を1回実行|称号「工房見習い」|
|Q05 次の道|職業図鑑で前提と武器を確認|プロフィールの紋章1個|
|Q06 仲間と歩く|他プレイヤーと1周クリア|称号「同行者」|

クエスト報酬はaccount_id/quest_id一意のoperationで付与する。クリックや再接続の回数で再取得できない。初回クエスト以外の反復クエストはv1の必須仕様に増やさない。

## 2. 消耗品

消耗品はスキルではなく物品使用。MPは消費しない。オート作戦で使用条件を指定し、1キャラあたり出撃指示中最大12個、1周最大4個を予約する。物品使用の共通CD30秒、1アクションを使用し、GCD1秒。行動不能中には使えない。

|ID|品名|対象・効果|NPC販売価格|
|---|---|---|---|
|C01|包帯|本人HPを最大HPの15%回復|30G|
|C02|治療薬|本人HPを最大HPの30%回復|80G|
|C03|小マナ薬|本人MPを最大MPの15%回復|40G|
|C04|マナ薬|本人MPを最大MPの30%回復|120G|
|C05|解毒薬|本人の毒1種解除|30G|
|C06|清声薬|本人の沈黙解除|60G|

NPC販売品は本人専用、売価0。通常素材やドロップアクセサリーをNPC販売で無制限に生成する機能は設けない。消耗品の効果を商人が強化する場合も、回復上限は対象の不足量。出撃終了で未使用の予約を解除し、使用した個数だけを消費する。

能力技の治療は物理/魔法のMP表を使い、消耗品と混同しない。MP薬の消費条件は本人MP20%以下を初期プリセットにする。アイテム枯渇時はスキルAIに戻り、存在しない品を再消費しない。

## 3. 通常敵の構成

各ダンジョンの4通常ルームは、1:近接3、2:近接2+術者1、3:近接1+支援1+遠隔1、4:精鋭1+近接2。テンプレート補正は近接=基準、術者=HP0.8/魔攻1.2/物防0.8、支援=HP0.9/魔攻0.8/魔防1.2、遠隔=HP0.9/物攻1.1、精鋭=HP1.8/攻撃1.1。

基準値と難易度倍率はWORLD_MMOを使用する。通常敵の技は単体PSまたは属性E、支援はHP50%未満の味方へMHをCD12秒で使用。精鋭はPAをCD15秒。難易度を上げても予告時間を0にはしない。

## 4. ボスの行動定義

以下のMP消費も対応する能動技の表に従う。ボスのMP切れ時は通常攻撃へ戻る。敵専用の沈黙などは確率を明示する。初期係数はスキル段階2を基本とし、難易度はステータス倍率で変える。

|ダンジョン|周期・優先条件|HP50%以下の変化|攻略上の役割|
|---|---|---|---|

|DNG05|雷Eを8秒、単体沈黙を24秒・予告3秒|沈黙対象を術者優先にする|物理の手当、清声薬、土攻撃|
|DNG06|氷Eを8秒、MSLを20秒|自己防御+15%を10秒、CD25秒|解除、貫通、火攻撃|

単体沈黙は命中後100%の基礎付与、対象の状態耐性で持続を減らす。DNG11は隊全員に同時付与し、回避・命中判定は設けない代わりに4秒の予告を表示する。敵のMP不足・CD中には詠唱を開始しない。

DNG12は、A隊=物理守護者（単体PS8秒/PA20秒、半分以下でPT12秒）、B隊=災厄守護者（闇E8秒/MDP18秒、半分以下でMDW24秒）、C隊=結界守護者（光E8秒/MS25秒、半分以下でMDS20秒）。各隊が自分の最終ボスを倒すと完了旗を立て、3旗達成で棄王の封印解除を演出し、最終報酬を全員へ確定する。4つ目の未設計戦闘を暗黙に追加しない。

先に倒した隊は他隊へ回復・攻撃を送らず観戦する。最終条件を未達成の隊が全滅した場合、最終目的が達成不能なのでレイドを失敗終了し全参加アカウントへ300秒を適用する。これはWORLD_MMOの「全員KOまたは時間切れ」に、目的達成不能による終了を補う規則である。中間ルーム報酬は失わない。

## 5. ギルド共同目標・実績

ギルド目標は週単位の共同クリア数を記録し、到達でギルドの掲示用紋章を解放する。物理/魔法ダメージだけを貢献として数えない。加入以前のプレイを遡って計上せず、同じrunを重複計上しない。v1では共有通貨・共有品の付与を行わない。

実績案は初出撃、初合成、初マスター、上級解放、基本20職マスター、全50職解放、仲間とクリア、レイド初クリアの8つ。Steamへの通知はDBで条件確定後に送信し、再送可能にする。実績通知失敗をゲーム報酬失敗にしない。

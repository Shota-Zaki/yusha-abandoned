## 2. Combatの公開契約

`Advance(snapshot, untilSimMs, contentBundle) -> { nextSnapshot, domainEvents }`

入力: 戦闘ID、Version、メンバー/敵の固定ビルド、現在HP/MP、行動予定、状態効果、召喚、脅威表、PRNG状態、イベント連番、現在の経過ms。

出力: 変更後の同じ状態と、順序が確定したイベント。ネットワーク・DB・実時間・端末FPSを直接参照しない。サーバーがuntilSimMsを計算して渡す。

全計算は整数。割合は10000=100%のbasis points。途中積算はchecked 64bit、各演算の直後に正の整数を切り捨てる。丸め方法を言語やCPUへ委ねない。マスタ上限は能力値100000、単発最終ダメージ2000000000とし、範囲外マスタは起動時に拒否する。

## 3. 能力計算

各基礎能力: `10 + floor((charLv-1)/2) + allocated + floor(jobLv*profileValue/50)`。

装備の加算値を加え、次に受動/バフの加算率を掛ける。能力増加の加算率上限+40%、低下下限-40%。HP/MPへの専用補正は能力補正と別グループだが同種内では加算する。

|値|式|
|---|---|
|最大HP|100 + 20*charLv + 12*VIT + 装備HP|
|最大MP|40 + 3*charLv + 8*WIS + 装備MP|
|物攻|10 + 4*STR + 2*DEX + 武器物攻|
|魔攻|10 + 5*INT + 武器魔攻|
|回復力|10 + 3*WIS + 2*INT + 武器魔攻|
|物防|2*VIT + 装備防御|
|魔防|2*WIS + 装備魔防|
|通常攻撃間隔|max(800, floor(2400*10000/(10000+25*AGI))) ms。その後速度バフを適用し再び800ms以上へ丸める|
|命中|clamp(7500,9900,9500+5*(攻撃者DEX-対象AGI)+命中補正)|
|会心|clamp(0,5000,500+2*DEX+会心補正)|
|回避|clamp(0,3500,2*AGI+回避補正)|

命中判定の後、回避可能な攻撃は対象回避を独立判定する。必中の回復・味方補助には命中/回避判定なし。攻撃魔法は命中判定あり、通常の物理回避では避けず、明示された魔法回避だけを別項目で扱う（v0.1では0）。

通常攻撃は武器のnormal_damage_typeに従う。杖・魔導書・魔杖・楽器は魔攻参照の無属性魔法通常攻撃、それ以外は物攻参照の無属性物理通常攻撃。通常攻撃のMPは0。沈黙でも通常攻撃は可能。

## 4. ダメージ・回復

```text
基礎 = floor(攻撃値 * スキル倍率bp / 10000)
防御後 = floor(基礎 * 1000 / (1000 + 有効防御))
属性後 = floor(防御後 * 属性倍率bp / 10000)
揺らぎ後 = floor(属性後 * randomInt(9500,10500) / 10000)
会心後 = 会心時 floor(揺らぎ後*15000/10000)、通常時は揺らぎ後
補正後 = floor(会心後 * (10000+与ダメ補正bp)/10000)
最終 = max(1, floor(補正後 * (10000-軽減bp)/10000))
```

有効防御=max(0,防御値×(1-貫通率))。貫通合計上限50%。物理は物防、魔法は魔防。無属性は属性倍率10000。

属性耐性Rは-25〜75（%）を標準範囲とし、属性倍率は`10000-100*R`。弱点はR=-25、耐性はR=25、強耐性はR=50。プレイヤー耐性も最大75%。単純な属性ジャンケンを固定せず、敵ごとに8耐性を持つ。

回復は回復力×倍率×回復補正、上限は対象最大HP-現在HP。会心・命中・防御・乱数揺らぎを適用しない。吸収は最終実ダメージを参照し、盾で吸収された分を回復源に数えない。盾はHPより先に消費。

かばうは最終被ダメージの指定割合を転送。元対象と転送先へ一度だけ適用し、転送ダメージへ防御式を二重適用しない。守護騎士等の「転送軽減」だけをその後に適用する。

例: 物攻300、倍率15000、防御200、無属性、揺らぎ10000、会心なしなら450→375→375ダメージ。端末表示はこのイベント値を用いる。

## 5. 時刻とイベント順

論理時刻は100ms単位。イベント優先キューで次の予定時刻へ飛ぶため、離席8時間を描画フレーム単位で再計算しない。

同じ時刻の順序: 期限切れ解除 → DoT/HoT/MP回復 → 詠唱完了 → KO反映・全滅判定 → 行動開始 → 通知スナップショット。各群はentity_id、event_seqの順に固定する。同時刻の攻撃完了を全て解決してからその群のKOを反映する。

敵全滅と味方全員KOが同時なら味方全滅を優先し、未確定の最終ルーム報酬は与えない。味方全員KO後に予約済みの蘇生を実行しない。召喚は生存判定の人数から除外する。

MP自然回復は5秒ごとにmax(1,floor(maxMP*0.005))、受動MRG補正を適用。戦闘中のHP自然回復は標準では0。街へ帰還するとHP/MPを全回復するが、出撃中の離脱・再接続だけでは回復しない。

## 6. 行動AI

プレイヤーは4能動系統の優先順位と、条件、使用段階、MP温存値を指定する。最大8ルール。サーバー側のホワイトリスト式DSLとし任意コードを実行しない。

評価順: 使用者が生存・行動可能 → 条件 → 対象有無 → CD → MP → 発動段階。上から最初に実行できる1つを選ぶ。全て失敗したら通常攻撃。通常攻撃にも対象がなければ待機。

条件: 味方最低HP%、味方KO数、敵数、対象の弱体/強化の有無、本人MP%、敵の予告範囲攻撃、指定属性耐性。未来の乱数・未表示の敵情報を条件にできない。

例: KOありなら蘇生 → 味方HP30%以下なら単体回復 → 複数味方HP60%以下なら範囲回復 → 攻撃。回復職の初期プリセットはMP25%を温存し、緊急回復だけ温存条件を超えて使える。

詠唱開始時にMP消費・CD開始。GCD1000ms、詠唱中の別行動なし。対象が詠唱完了前に不適格になった場合は、同じ対象規則で1回再選択し、対象なしなら空振り。MP返却なし。戦闘終了済みなら予約イベントをキャンセルし追加報酬なし。

自己回復や弱体が無意味な場合は発動しない。例えば全快への回復、同等以上の長時間バフの再付与、ボス免疫の妨害を避ける。消耗品は出撃時に使用許可と上限個数を予約し、MP不足の無限ループ対策に使う。

## 7. 脅威と隊列

4人に前列2/後列2。レイドは4人×3隊。単体敵AIは脅威最大を基本標的とし、同値はentity_id昇順。ダメージの100%、実回復量の50%を脅威として加算。挑発は期間中だけ選択を上書き。死亡者の脅威は0、蘇生は0から。

隊列は標的条件と演出に使う。手動の瞬間回避や移動操作をボス攻略条件にしない。予告攻撃には出撃前AIの防御・盾・回復設定で対応する。

## 8. 出撃状態機械

`IDLE → RESERVED → RUNNING → SETTLING → IDLE`。

全滅は `RUNNING → WIPED → COOLDOWN → IDLE`。`cooldown_until` はアカウントに保存。手動での危険な途中撤退もCOOLDOWN300秒。通常の「次の周回で停止」は現在周回の精算後IDLE。

作戦指示にはexpires_at=start+8時間を持たせ、接続/切断で延長しない。期限以前に起きるイベントだけを評価し、期限時点で既に完了したルーム報酬を精算して終了。途中ルームは未報酬、期限終了自体は全滅制限なし。

全滅後の既定動作は停止。オプションで300秒後の自動再挑戦を許可するが、1指示につき最大3回、期限内のみ。サーバー障害の再試行をプレイヤーの失敗回数として数えない。

## 9. 離席・競合・障害

サーバーが進行を保持し、ユーザーのPCを起動し続ける必要はない。接続中と離席中に同じAdvanceを使う。プレイヤーが戻ったときだけ別計算で大量の報酬を作らない。

ワーカーは短いDB取引でleaseを取得し、ロック外で上限10秒分または200イベントを計算、CAS版番号とlease_tokenでチェックポイントをコミットする。時間枠を超える追いつきはジョブを継続して公平に処理する。最大遅延を監視し、追いつき中は変更系操作を202で待機させ、未確定報酬を先渡ししない。

1ルームの報酬IDはexpedition/run/room/recipient/ordinalから一意に作る。チェックポイント・報酬・台帳・outboxを同一取引に保存。ワーカー停止後の再計算は同じ乱数と同じIDに収束する。

報酬、命中、会心、装備ロールには独立した乱数ストリームを使い、演出の追加でドロップ列がずれないようにする。サーバーで暗号学的乱数種を生成し、Version固定のPRNGで再現する。種は秘匿し、操作リクエストには含めない。

## 10. レベルアップと変更タイミング

ルーム終了時にEXPを確定し、表示Lvは更新。実戦の能力値は出撃時のビルドスナップショットを当該周回の終了まで保持する。次周回開始時にサーバーが最新Lvと保存済み配分から再作成する。新ポイントは自動配分せず未使用に追加。

パーティーの転職・装備・参加者変更は次の出撃指示から。ソロでも途中で装備を交換して乱数を選別できない。プレビューは参考であり、成功保証を表示しない。

## 11. 境界テスト

Lv1/49/50/100、Rank0/1/4/5/9/10/19/20、ポイント不足・負数、前提職の一部未達、禁止武器、HP0と同時蘇生、MPが消費ちょうど/1不足、全滅後299999ms/300000ms、接続切断、同じ報酬の再送、lease期限切れ、2ワーカー競合、バフ再帰、整数オーバーフローを必須とする。

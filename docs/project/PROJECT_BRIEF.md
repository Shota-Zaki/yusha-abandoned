# 勇者アバンド — 企画概要

Version: 0.2 / 2026-09-13 / 状態: ユーザー回答を反映した設計ベースライン

## 目的

短時間で育成方針を考え、離席中にも冒険が進み、戻ると装備と職業の選択肢が増えている、協力型の放置オンラインRPGを作る。育成した職業・装備・作戦を定期PvP大会でも活用する。

キャッチコピー案: 「席を外しても、冒険は続く。」

世界設定: 王国に見捨てられた冒険者たちが、廃都アバンドを拠点に各地の災厄へ挑む。勇者は最初から与えられる称号ではなく、多くの職業を経験して到達する選択肢の一つ。

## プレイヤー体験

職業を決める → ポイントを振る → 装備と行動優先順位を整える → ダンジョンを選ぶ → 自動で探索・戦闘する → 成果を受け取る → 交換または合成でビルドを更新する。

街・チャット・交換・4人協力・12人レイド・ギルドでつながる。定期大会でプレイヤー同士のオート戦闘も行う。手操作の反射速度ではなく、育成と作戦の判断を中心にする。

## 対象・スコープ

SteamのPCユーザー。育成、装備厳選、転職の組み合わせ、協力プレイを好み、長時間の手操作を必須にしたくない人。低負荷で他のPC作業と両立しやすいことを目指す。

正式版の設計対象: 50職、8属性、12ダンジョン、6難易度、5部位装備、装備ソケット、合成、交換、取引所、街、4人協力、12人レイド、ギルド、定期PvP大会、フレンド、通報、運営管理。

最初の縦切り実装: 戦士・白魔法使い・黒魔法使い・僧侶、街道1つ、低難易度、1人＋NPC、戦闘・報酬・全滅制限・装備合成まで。正式版を4職へ縮小する意味ではない。

## 確定した方針

Steamで600円買い切り。軽量化を重視。街40人/通常4人/レイド12人。1アカウント1活動キャラ、通常同時出撃1件、1回8時間の放置指示。初級20/上級20/複合10の50職、キャラLv100・職Lv50、職固定4能動+2受動、職外スキル継承なし。未合成品は外せば交換可能、合成後は永久に本人専用。PvE中心＋定期PvP大会。

## 未確定・提案

「めっちゃカメレオンのように運営負担を抑える」という方向を採用する。完全P2Pと最小の公式判定基盤のどちらを優先するか、費用上限はD01に残る。Steamだけで任意のMMO処理を無料ホストできる前提は置かない。

Windows優先、Godot 4系 .NET/C#＋Compatibilityを第一候補とするが、軽さを実測して確定する。大会は週次4対4の登録ビルド戦を提案。頻度・人数・補正等はPVP_TOURNAMENTに区別して記録する。

## 成功条件

- 初回15分程度で出撃、報酬、装備比較、ポイント配分を体験できることをUX検証する。
- 全初級職が終盤の少なくとも1種類の攻略目的で採用理由を持つ。
- 同一条件のオンライン処理と離席分の処理が同じ結果になる。
- 再送・切断・競合・復旧で所持品と通貨が増殖しない。
- 放置するほど操作頻度が増えるのではなく、判断したい場面だけ操作できる。
- 定期大会の結果が登録ビルドと固定ルールから再現でき、PvEの育成状態を壊さない。
- 軽量性をRelease版の描画・RAM・配布サイズで測定する。

売上、継続率、対応CCU、動作スペック、運営費の実績はまだない。設計値を検証済み性能や採算の保証として扱わない。

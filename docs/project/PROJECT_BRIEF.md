# 勇者アバンド — 企画概要

Version: 0.1 / 2026-09-13 / 状態: 仮決定を含む設計ベースライン

## 目的

短時間で育成方針を考え、離席中にも冒険が進み、戻ると装備と職業の選択肢が増えている、協力型の放置オンラインRPGを作る。

キャッチコピー案: 「席を外しても、冒険は続く。」

世界設定案: 王国に見捨てられた冒険者たちが、廃都アバンドを拠点に各地の災厄へ挑む。勇者は最初から与えられる称号ではなく、多くの職業を経験して到達する選択肢の一つとする。

## プレイヤー体験

職業を決める → ポイントを振る → 装備と行動優先順位を整える → ダンジョンを選ぶ → 自動で探索・戦闘する → 成果を受け取る → 交換または合成でビルドを更新する。

他プレイヤーとは街・チャット・交換・4人協力・12人レイド・ギルドでつながる。単にランキングだけを共有する形式ではなく、同時接続と実際の共同戦闘を持つ。

## 対象・スコープ

SteamのPCユーザー。育成、ハックアンドスラッシュ、転職の組み合わせ、協力プレイが好きで、連続した手操作を必須にしたくない人。

正式版の設計対象: 50職、8属性、12ダンジョン、6難易度、5部位装備、装備ソケット、合成、プレイヤー間交換、取引所、街、4人協力、12人レイド、ギルド、フレンド、報告機能、運営管理。

最初の縦切り実装: 戦士・白魔法使い・黒魔法使い・僧侶、廃道1つ、低難易度、1人＋NPC、戦闘・報酬・全滅制限・装備合成まで。最終仕様の50職を4職へ縮小する意味ではない。

## 仮決定

Windows優先、Godot .NET/C#、運営管理型バックエンド、買い切りを第一候補、PvE中心、1アカウント1活動キャラクター、1回8時間の放置指示、街40人/通常4人/レイド12人。採否はOPEN_DECISIONSに集約する。

## 成功条件

- 初回15分程度で出撃、報酬、装備比較、ポイント配分を体験できることをUX検証する。
- 全初級職が終盤の少なくとも1種類の攻略目的で採用理由を持つ。
- 同一条件のオンライン処理と離席分の追いつき処理が同じ結果になる。
- 再送・切断・並行操作・障害復旧で所持品と通貨が増殖しない。
- 放置するほど操作頻度が増えるのではなく、判断したい場面だけ操作できる。

売上、継続率、同時接続数の実績はまだ存在しない。開発規模・費用・納期を確定値として扱わない。
